# AirFit Planner

AirFit Planner is a minimalist wellness dashboard that adapts focus, movement, and recovery plans using body-measurement and air-quality context.

## What it does

- Accepts multiple inputs: height, waist, PM2.5, session intensity, and goal.
- Produces multiple outputs: readiness score, plan duration, generated plan, air-quality guidance, and body-measurement context.
- Visualizes compact air-quality trends and reference body-measurement statistics.

## Run locally

```bash
npm install
npm run dev
```

## Verify

```bash
npm run lint
npm run build
```

## Notes

The app uses compact, checked-in summary data so it runs without external services.
